# Hardware bring-up and commissioning gates

This low-voltage project is not a certified protection system. No actual hardware was present for these software checks. Physical commissioning is a separate acceptance activity requiring qualified supervision, current-limited instruments and the actual component datasheets.

1. Resolve battery chemistry, pack PCM evidence, charge/discharge currents, thermistor limits, panel coldVoc and module schematics. Confirm exact MCU/display variants and DC relay BBM/inductive ratings. Review custom carriers before fabrication. Verify fuse interrupt ratings, wire ampacity, connectors and source fault energy.
2. With all sources disconnected, continuity-check every harness against controller_wiring.csv and net drawings. Check no shorts between3.3V/5V/12V, power return routing and fuse placement. Check both INA address pins physically, then scan each independent I2C bus.
3. Power controllers only from isolated adapters. Verify all relay/branch outputs fail low through reset, watchdog and unplugged GPIO. Confirm e-stop physically opens bus energy independent of MCU. Keep battery disconnected.
4. Test eFuse channels individually with independently current-limited bench sources and dummy loads. Confirm ramp, forward limit, reverse blocking, FLT indication, EN off current and latch/reset. Do not create uncontrolled panel or battery shorts. A failed-short eFuse must be isolated by upstream protection/service switch.
5. Calibrate monitors with DMM/reference shunts, signed charge/discharge, gain/offset and zero. Validate temperature/humidity timeout and LDR range. Disconnected sensor must become invalid, never plausible zero. Check radio supply ripple and antenna connection before TX.
6. Characterise each boost at minimum input voltage with resistor loads. Record input current, output ripple, thermal steady state, UVLO hysteresis, current-limit response and shutdown backfeed. Test9W pulse only if converter/source is rated. Verify solar qualification resistor guarded and hardware fail-on dissipation safe.
7. Commission charger on a battery simulator/current-limited test fixture per manufacturer procedure before connecting verified pack. Set CC/CV, input regulation, TS/NTC cutoffs, termination and status. Check charging stop at temperature extremes using an approved NTC simulator, not heating/damaging a real cell.
8. With sources provided by protected bench supplies, scope KEN/KSEL switching. Verify master opens before selector moves,250ms exceeds actual release/bounce, sources never parallel, droop revokes solar, and welded/stuck drive simulations use current limits. Confirm all four binary relay combinations match truth table.
9. Test each load branch separately, then staged restoration with critical load first. Measure fan startup/stall transient and suppression. Reject firmware thresholds that trip valid startup; never raise thresholds above independently protected limits.
10. Integrate real PV, then protected battery, one path at a time. Record polarity, temperature and fused current. Disconnect LoRa/C3/laptop and confirm local source/load fallback. Reset each MCU and observe physical outputs. Only then attempt a supervised full demonstration.

Acceptance record must include instrument models/calibration, actual BOM revisions, wiring revision, measured waveforms, thermal results, fault response latency, operator/date and residual risks. Software test output cannot fill these boxes. Use dedicated DC disconnect, insulated enclosure and battery handling guidance from pack manufacturer. Never recharge damaged/swollen cells or bypass protection.

## Shared-PV and charge-inhibit commissioning

Verify the dedicated charger input fuse/reverse path and KPV NO solar-input path; unused NC must be insulated. Confirm PB10 drives only the signal-MOSFET gate, whose drain pulls MPPSET pin2 below75mV; release must restore the original divider. Check PB1 ADC1_IN9 scaling against a DMM and actual VDDA. Do not assume an anonymous charger board exposes MPPSET or is already configured for1S.

With an independently current-limited PV emulator/bench fixture, sweep available current/source impedance and apply staged load steps. Scope PV voltage, solar12 output, charge current and net battery current. Confirm charging demand falls under droop, inhibition acts for proof/transfer/recovery, recovery does not chatter and the boost respects its own current limit/UVLO. Validate charging permitted, inhibited, terminated and unavailable. A constant-power boost can destabilize a weak source; passing software tests is not evidence of analog loop stability.
