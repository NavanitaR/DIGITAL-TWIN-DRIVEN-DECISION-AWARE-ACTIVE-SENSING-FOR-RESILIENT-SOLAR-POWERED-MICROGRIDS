# Binary wire protocol v1

Little endian. Magic0xA7,version1,type1byte,node1byte,sequenceuint16,device uptime ms uint32,payload lengthuint8,payload0..180bytes,CRC16-CCITT-FALSEuint16. Header11bytes, overhead13, maximum193. CRC polynomial0x1021 init0xFFFF, no reflected bits, no xorout. MCU packed structs consist only of floats followed by4bytes; static tests ensure76byte sensor and64byte central layouts. IEEE754 float32 assumed/verified on targets. Cross-device uptime is not UTC; host receipt time must be logged separately. Sensor sample counter wraps at256, packet sequence at65536; neither proves globally unique identity across reset.

Types1..13: HEARTBEAT,SENSOR_REPORT,PANEL_REPORT,FAULT_EVENT,MEASUREMENT_REQUEST,MEASUREMENT_RESPONSE,PANEL_ISOLATION_REQUEST,ACK,NACK,CONFIG_GET,CONFIG_SET,CONTROL,CENTRAL_REPORT. S3 reports its panel condition/fault masks through SENSOR_REPORT; it does not emit a separate FAULT_EVENT in this version. STM32 emits PANEL_REPORT for local PV voltage and charge-inhibit status, as specified below. Node1 S3,2 central,3 C3,9 host. Reject unknown types, wrong lengths, CRC failures and unexpected command-origin IDs.

Sensor payload76bytes:18float values (clusterA temp,humidity,V,I,P,relativeLight; clusterB same; PV1..4power; PV1/2current), then isolated mask,monitor health mask, fault mask,sample counter. All four panel currents are sensed locally; only first two additional current values fit this v1 report alongside power values. Missing analog values encoded IEEE NaN and converted to null by host, never zero. Health bits0..5 map clusterA,B,PV1..4. Fault bit indicates a suspected condition; exact internal latch cause is local diagnostic information and not fully encoded in this payload.

Central payload64bytes:15floats batteryV,signedA,SOC,busV,solar capacity boundW,totalLoadW,load1W,load2W,load3W,load1V,load2V,load3V,load1A,load2A,load3A; sourceenum0off1solar2battery,loadmask,stateenum,healthmask. **solar_w in hardware central report is a qualified capacity bound, not directly measured generated power.** Dashboard must label/interpret it accordingly; panel powers are measurements. InitialSOC is uncalibrated estimate. Invalid central sensor frames are rejected by host; stale timeout then applies.

Host CONTROL payload4bytes: opcode1load2source3panel4fresh5auto6supervisoryService,target0based,value,confirmed0/1. Source value0off1solar2battery; panel value1isolated0connected; load0off1requestOn. Opcode6 uses target byte as0/1/4/6W service budget; the controller keeps critical service local and applies all safety limits. Central validates and transforms panel/fresh into LoRa request. ACK/NACK payload request sequenceuint16,statusbyte:0accepted,1confirmation missing,2invalid,3unsafe/unavailable,4busy,5retry exhausted. Accepted is not proof of physical actuation; verify subsequent telemetry. Source request ACK precedes delayed FSM execution. Local panel ACK is forwarded after node reply.

UART1152008N1 uses COBS(packet)+zero. Oversize/corrupt frame drops and next delimiter resynchronises. Gateway8-frame FIFO expires data after5s; it forwards no retained commands. MQTT QoS1 subscriptions may duplicate commands; central and node cache most recent successful command sequence. Only one outstanding LoRa transaction with at most3 sends and15s response wait per send. Driver remains half-duplex, checks TxDone with1.5s timeout; scheduler limits conservative airtime to<=5% and uses SF7BW125CR4/5. No simultaneous RX/TX. Both devices use a matching sync word0x42 and433.92MHz.

MQTT topics microgrid/v1/up and /down contain raw wire packets, not JSON; /gateway is retained online/offline diagnostic. Host pending command expires after65s and remains pending until ACK; MQTT publish acceptance is not device acknowledgement. On mode change pending map is discarded and hardware publishing ceases. Broker must bind a trusted interface with authentication/firewall for hardware; backend defaults loopback. Protocol CRC is not authentication: untrusted RF peers could spoof commands. This prototype is for supervised isolated lab operation; add authenticated MAC/session replay protection for adversarial use.
